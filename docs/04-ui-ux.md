## 1. 信息架构

```
底部 TabBar（3 项）
├── 项目（index）          最近项目列表 / 新建 / 存储管理入口
├── 录音（record）         麦克风录音主入口
└── 我的（mine）           成品列表 / 设置 / 隐私说明 / 关于

二级页面（无 TabBar）
├── editor                  单轨波形编辑器（核心页面）
├── mixer                   多轨拼接与混音
├── export                  导出配置与进度
└── settings                性能模式、默认格式、存储清理
```

> **为什么把"录音"独立成 Tab**：录音是本产品最高频的入口，让用户在首页一步开始，减少"新建 → 选择来源"的层级。

## 2. 页面流程

```
项目列表 ──新建──┬──► 录音页 ──停止──┐
                 │                    ├──► 编辑器（导入/转码完成后自动进入）
                 └──► 选择文件 ───────┘
编辑器 ──添加轨道/合并──► 混音页 ──返回──► 编辑器
编辑器 ──导出──► 导出页 ──成功──► 分享面板 / 成品列表
```

## 3. 编辑器页面（核心）

> **M1 实现范围（单素材切割视图）**：波形显示**焦点素材**（工程第一条轨道第一个片段引用的素材）的峰值，横轴为素材时间。单片段工程的素材时间与工程时间轴一致，因此选区与播放头可直接用于 `edl/ops` 的时间轴操作；多片段拼接与跨轨拖动在混音页完成（§2 的页面流程即如此设计）。波形数据直接以引用传入画布组件，不经 `setData`。

### 3.2 波形画布规格

| 项 | 规格 |
| --- | --- |
| 实现 | `Canvas 2D`（`type="2d"` + `SelectorQuery.nodes()` 拿 node 与 context） |
| 尺寸 | 逻辑宽度 = 屏宽；`dpr` 适配（`canvas.width = width * dpr`） |
| 竖向构图 | 波形振幅占画布高度 70%，上下留白便于显示选区手柄 |
| 波形绘制 | 以水平中线为 0，每像素画一条 `min..max` 竖线；正负半轴对称着色 |
| 波形着色 | 已选区（选中/播放过）用强调色，未选区用低饱和灰蓝；超 0dBFS 峰值段标红 |
| 时间→像素 | `x = (t - viewStartSec) * pxPerSecond`；`pxPerSecond ∈ [4, 400]`（即 0.0025s/px ～ 0.25s/px） |
| 缩放锚点 | 双指捏合时以**捏合中心对应的时间点**为锚保持不动 |
| 播放头 | 1.5px 竖线 + 顶部小三角；播放中每 `onTimeUpdate`（约 100ms）更新，并用 `requestAnimationFrame` 做插值平滑 |
| 选区 | `rgba(主色, 0.18)` 矩形 + 左右 8px 垂直手柄（点击热区 24px，符合可点性） |
| 淡入淡出 | 选区上边缘的小三角手柄，横向拖动改时长，实时在波形上叠加一条包络曲线 |
| 网格 | 缩放 ≥ 60px/s 时显示 0.1s 细网格线；≥ 20px/s 显示 1s 网格线 |
| 重绘策略 | 拖动手势期间只重绘位移（离屏 canvas `drawImage` 平移 + 边缘补绘）；手势结束后整绘一次 |
| 低端机降级 | 限帧 30fps、取消网格（引擎侧的抽样聚合见 [03 §4.3](./03-audio-engine.md#43-绘制时的选择与采样)） |

### 3.3 手势映射

| 手势 | 目标 | 行为 |
| --- | --- | --- |
| 单指拖拽示波区空白 | 波形区 | 移动播放头（实时更新时间显示，松手才 seek 播放器，避免频繁 seek） |
| 单指拖拽选区内部 | 选区 | 整体平移选区（保持时长），边缘吸附到片段边界/网格 |
| 单指拖拽选区手柄 | 选区边缘 | 调整选区起止；放大到 ≤ 20ms/px 时启用"精细模式"（步进 5ms + 震动反馈） |
| 双指捏合 | 波形区 | 以捏合中心为锚缩放时间轴（同时自动切换峰值层级） |
| 双指横向滑动 | 波形区 | 平移时间轴视口 |
| 长按波形 | 波形区 | 唤出上下文菜单：分割 / 静音 / 复制 / 删除 / 设为噪声样本（降噪用） |
| 长按工具按钮 | 工具栏 | 显示参数说明与预设列表 |
| 双击波形 | 波形区 | 全选 / （已有选区时）取消选区 |
| 拖动片段块 | 单轨拼接视图 | 拖动排序，带吸附与插入指示线 |

**手势冲突处理规则（必须在实现时明确）**
1. 手指落在**选区手柄热区** → 优先判定为手柄拖动，不移动播放头。
2. 双指同时落下 → 取消进行中的单指操作（回滚该操作的未提交状态）。
3. 手势过程中**不触发渲染**，只在手指抬起后提交一次状态变更（性能关键）。
4. 编辑期间禁止 `page scroll`（编辑器页面 `page-meta` 关闭滚动，Canvas 用固定高度）。

### 3.4 交互状态机

```
        ┌──────────────────────────────────────────┐
        │                                          │
   ┌────▼────┐  点击播放   ┌────────┐  播放结束/暂停  │
   │  IDLE   ├────────────►│ PLAYING├───────────────┤
   └────┬────┘             └───┬────┘               │
        │ 按下拖动/选区          │ 编辑操作打断播放       │
   ┌────▼────────┐             │                    │
   │  GESTURING  │◄────────────┘                    │
   └────┬────────┘                                  │
        │ 抬起提交                                    │
   ┌────▼────────┐  触发需要重渲染的操作                │
   │  EDITING    ├──────────────►┌──────────────┐    │
   └─────────────┘               │ PREPARING    │    │
                                 │ （渲染预览中） │    │
                                 └──────┬───────┘    │
                                        │ 完成         │
                                        └─────────────┘
   ┌──────────────┐  导出
   │  EXPORTING   │（进度 / 可取消，屏蔽编辑操作）
   └──────────────┘
```

**规则**
- `PREPARING` 期间允许继续编辑（编辑会取消当前渲染并标记脏），但 UI 显示轻量进度提示，不阻塞。
- `EXPORTING` 期间锁定编辑（避免 EDL 在渲染途中变化导致结果不一致）：EDL 在导出开始时**深拷贝快照**。
- 任何状态下的 `onHide` → 保存 EDL、暂停播放与渲染。

### 3.5 工具栏与参数面板

| 入口 | 交互形式 | 参数 |
| --- | --- | --- |
| 淡化 | 底部抽屉 | 时长（0～5s，滑杆）、曲线（线性/等功率）、应用到选区起/止/两端、试听按钮 |
| 音量 | 底部抽屉 + 波形上叠加包络线 | -30～+12dB 滑杆、峰值/RMS 实时读数、归一化按钮 |
| 效果 | 全屏面板，分「基础/均衡/动态/特效」四组 | 每组都是"预设卡片 + 少量参数"，避免专业术语堆砌 |
| 变速 | 底部抽屉 | 0.5×～2× 滑杆（先提供"只改变速度"的玩具级实现，标注音调会变化） |
| 降噪 | 底部抽屉 | 降噪强度（0～100%）、"学习噪声样本"按钮（需先选中一段纯噪声） |

**参数调节的性能策略**：滑杆 `changing` 事件只更新 UI 数字与包络预览（不渲染）；`change`（松手）后才触发预览渲染。防止拖动滑杆时连续触发渲染。

## 4. 其他页面要点

### 4.1 项目列表（index）

- 卡片内容：项目名、时长、更新时间、**迷你波形缩略图**（用最高层峰值绘制，约 40px 高，无交互）。
- 卡片右侧操作：`⋯` 菜单（重命名/复制/删除/导出）。
- 顶部：`新建项目` 主按钮 + 存储占用提示（警戒阈值与提示行为见 [05 §5](./05-data-model.md#5-容量策略)）。
- 空态：插画 + "录一段，或导入微信里的音频文件" + 两个按钮。

### 4.2 录音页（record）

```
┌────────────────────────────────────┐
│           录音                      │
│                                    │
│   00:23.4              ● 录音中     │
│   ▁▃▅█▇▅▃▁▂▄█▆▃▁▁▂▃▅▃  ← 实时波形  │
│   ─────────●─────────  ← 电平表     │
│                                    │
│       ⏸ 暂停        ⏹ 完成          │
│                                    │
│   格式 PCM · 44.1kHz · 单声道        │
│   录音上限 10 分钟                   │
└────────────────────────────────────┘
```
- 首次进入展示麦克风用途说明（合规要求），失败时引导 `wx.openSetting`。
- 录音的格式/采样率/码率/分帧参数规范在 [03 §3](./03-audio-engine.md#3-素材导入管线)，本文不重复；页面只负责展示当前格式与上限。
- 剩余时长倒计时（依据 `duration: 600000` 上限），距上限 30s 时提醒。
- 中断（来电/切后台）→ 停止并保存已录内容，返回时提示"已保存前 xx 秒"。

```
│        ▃▅▇█▇▅▃▁▁▂▃▅▃▁▁▂▃▅▃▁▁▂▃▅▃     │
├──────────────────────────────────────┤
│        ┃  ← 播放头 / 对齐参考线        │
│  00:00   00:15   00:30   00:45       │

```
- 轨道高度 72px（含 40px 波形 + 名称/控制行）。
- 片段块显示：缩略波形、时长、淡入淡出斜角标记。
- 长按片段 → 移动 / 复制 / 删除 / 分割 / 淡入淡出 / 增益。
- 拖动到另一轨道 → 跨轨移动。

### 4.4 导出页（export）

| 区块 | 内容 |
| --- | --- |
| 格式 | WAV（默认，无损）/ MP3（P1，码率选择） |
| 采样率 | 44100 / 22050 / 16000（显示"音质/体积"权衡提示） |
| 声道 | 单声道 / 立体声 |
| 归一化 | 开关（默认开，峰值 -1dBFS）+ 限制器开关（默认开） |
| 预估信息 | 时长、预估文件大小、峰值/RMS 读数（超 100MB 直接禁用导出并给建议） |
| 试听 | 播放最终渲染（若已渲染则秒播） |
| 导出 | 主按钮 → 进度条（百分比 + 阶段文案 + ETA）→ 可取消 |
| 成功态 | 显示文件信息 + 「发送给朋友」（`shareFileMessage`）+ 「保存到本地（PC）」+ 「返回编辑」 |
| 失败态 | 明确原因 + 可执行建议（清理存储 / 降低采样率 / 缩短时长） |

**成功态文案必须写清"文件在哪"**：小程序无法把音频写入手机文件管理器，文案为"已保存在「我的 → 成品」，可随时发送给朋友"，避免用户以为已存进手机音乐库。

> **M1 落地状态**：导出页（`pages/export/`）已实现配置、预估、进度与取消、成功态分享；归一化按**峰值金字塔估算**决定总线增益（`core/engine/export-plan.ts`），不为测量峰值而多渲染一遍；MP3 与码率选项属 P1，M1 只出 WAV。

### 4.5 我的（mine）

- 「成品」列表：文件名、时长、体积、创建时间、分享/重命名/删除。
- 「存储」区块：各类占用（素材/峰值/工程/成品）+ 清理按钮（保留工程引用的素材，其余可清）。
- 「设置」：默认导出格式、默认录音采样率、性能模式（自动/高/低）、清空缓存。
- 「隐私与关于」：隐私政策入口、麦克风用途说明、第三方开源许可（lamejs 等）。

## 5. 视觉规范

| 项 | 值 |
| --- | --- |
| 主题 | 编辑器默认**深色**（波形与选区对比度更好），其他页面跟随系统 |
| 背景 | `#12151A`（深色） / `#F5F6F8`（浅色） |
| 表面 | `#1C2029` / `#FFFFFF` |
| 波形主色 | `#4C8DFF`（未选中） |
| 波形选中色 | `#19C37D`（已处理/已播放区） |
| 播放头 | `#FF4D4F` |
| 选区高亮 | `rgba(76,141,255,0.18)` + 边框 `#4C8DFF` |
| 警告（削波） | `#FF7A45` |
| 主按钮 | `#4C8DFF`，圆角 12px，高度 96rpx |
| 工具按钮 | 图标 48rpx + 文字 22rpx，热区 ≥ 88rpx |
| 字体 | 系统字体，数字（时间）用等宽变体，避免跳动 |
| 圆角 | 卡片 16rpx，抽屉 24rpx（顶部圆角） |

**反馈规范**
- 破坏性操作（删除片段/项目）→ `wx.showModal` 确认。
- 轻量结果（裁剪完成、已复制）→ `wx.showToast`（`icon: 'none'`，1.5s）。
- 精细调节到网格/边界 → `wx.vibrateShort({type:'light'})`（可关闭）。
- 长任务（导入/渲染/导出）→ 内联进度条 + 可取消，**不用全屏 loading 遮罩**（用户可能想继续看波形）。

## 6. 空态、加载态、错误态

| 场景 | 呈现 |
| --- | --- |
| 无项目 | 插画 + "还没有作品，先录一段试试" + 主按钮「开始录音」 |
| 打开项目正在恢复 | 骨架屏波形（灰条纹）+ "正在准备波形…" |
| 波形构建中（首次导入） | 进度环 + "正在分析音频 45%"（可后台继续编辑已就绪部分） |
| 解码不支持 | 居中卡片：格式名 + "暂不支持该格式" + 建议（转 WAV/MP3）+ 「仍要尝试」 |
| 内存不足 | "音频过长（12 分 30 秒）" + 建议裁剪到 10 分钟内 或 降为 22.05kHz |
| 存储不足 | 显示占用明细 + 一键清理（仅清成品与无引用素材） |
| 渲染失败 | 内联错误条 + 「重试」+ 「反馈问题」（附工程快照路径，便于排查） |

| `ProgressTask` | 长任务进度条（导入/渲染/导出） | `stage`、`ratio`、`etaSec`、`bind:cancel` |
| `EmptyState` | 空态插画 + 文案 + 按钮 | `type`、`title`、`desc`、`actions` |

> **M1 落地状态**：`WaveformCanvas`（Canvas 2D + 手势 + 离屏位图复用）、`TimelineRuler`（刻度由页面算好后传入）、`EmptyState` 已实现；其余组件随对应页面落地。

## 8. 待确认的交互问题

1. 单指拖动是"移动播放头"还是"框选"？（当前定为移动播放头，框选走选区手柄 + 双击全选。需在 M1 用真机用户测试验证）
2. 是否需要在波形上直接拖拽片段（而不用进混音页）？倾向 M2 再评估，先保证单轨切割体验。
3. 撤销栈的 UI 反馈：是否需要"操作历史列表"（像专业软件那样可跳转）？MVP 只做两步按钮。
4. 横屏是否支持？**MVP 不做横屏**（波形变宽收益有限，且要处理安全区与适配成本）。
