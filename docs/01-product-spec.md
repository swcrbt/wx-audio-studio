## 1. 背景

微信生态里"录一段音频"很容易，但"把录到的音频剪好"很难：用户要么在手机上装专业 App（学习成本高、体积大），要么把文件传到电脑用 Audacity（链路长）。小程序天然具备"即用即走 + 微信内直接分享"的优势，适合承接**轻量、成品导向**的音频编辑需求。

**产品定位一句话**：在微信里把声音剪干净、拼完整、处理好，然后导出发给别人。

## 2. 目标用户与典型场景

| 用户 | 场景 | 关键诉求 |
| --- | --- | --- |
| 内容创作者 / 播客新手 | 录一段口播，剪掉口误和长停顿，加个片头音乐 | 剪辑精准、去停顿快、能拼接 |
| 学生 / 职场人 | 录一段英语口语作业、会议发言 | 录完能试听、裁掉头尾、音量统一 |
| 音乐爱好者 | 把自己唱的一段和伴奏对在一起 | 多轨对齐、音量平衡、简单混响 |
| 教师 / 培训者 | 把多段讲解录音拼成一节课 | 批量拼接、顺序调整、统一响度 |
| 普通用户 | 微信收到一段音频，想剪掉前后杂音再转发 | 导入方便、导出微信内可直接分享 |

## 3. 核心用户流程

```
录音 / 导入微信聊天文件 / 选手机本地音频
        ↓
   自动转成标准中间格式（PCM WAV）+ 生成波形
        ↓
   波形编辑：裁剪 · 分割 · 删除 · 移动 · 淡入淡出 · 音量
        ↓
   拼接与混音：多轨 · 叠加 BGM · 交叉淡化 · 音量包络
        ↓
   音效：EQ · 压缩 · 变速 · 变调 · 降噪 · 回声/混响
        ↓
   导出：选格式/采样率 → 试听 → 保存/分享
```

优先级定义：**P0 = MVP 必须**，**P1 = 首个正式版**，**P2 = 增强/远期**。

## 5. MVP 边界

**MVP = 第 4 节中全部 P0 项**（P0 清单即范围定义，此处不重复罗列）。P0 之外一律不进 MVP。

以下是**边界澄清**，仅说明 P1/P2 与范围外事项为何不在 MVP：

**范围外（不做，且无实现计划）**：
- ❌ 服务端处理、账号体系、云同步
- ❌ 视频编辑、音频转视频、音视频合成
- ❌ 语音转文字 / 自动字幕
- ❌ 云端素材市场、音效商店（版权风险）

**已在清单内但延后到 P1/P2（原因）**：
- ❌ 多轨 > 2 轨、音量包络关键帧、谱减降噪、变调、混响 → 实现成本高，先验证核心剪辑链路
- ❌ 实时特效监听 → 端上无 `OfflineAudioContext`，实时链路（`createScriptProcessor`）的稳定性与延迟待实测（[02 DB-04](./02-platform-capability.md#5-待实测验证清单spike-任务)）。它不是核心价值，MVP 采用「参数化 + 快速预览渲染」路线，用 200ms～1s 渲染延迟换确定性

## 6. 关键产品指标

| 指标 | 目标 |
| --- | --- |
| 冷启动到首页可交互 | ≤ 1.5s（中端机） |
| 1 分钟音频导入（含转码+波形） | ≤ 3s |
| 波形缩放/拖动帧率 | ≥ 45fps（中端机），≥ 30fps（低端机） |
| 选区渲染预览（30s 内） | ≤ 500ms |
| 导出 3 分钟音频为 WAV | ≤ 15s |
| 导出失败率 | < 0.5% |
| 首启到产出第一个成品的完成率 | > 60%（体验版埋点） |

## 7. 竞品参考与差异化

| 参考对象 | 借鉴点 | 本产品的差异/取舍 |
| --- | --- | --- |
| 剪映（音频部分） | 波形+时间轴+吸附的成熟交互范式 | 我们不做视频，专注"音频干净、拼得顺、导得快" |
| GarageBand（iOS） | 多轨与效果器概念、循环素材 | 去掉复杂音乐制作能力，降低门槛 |
| Audacity（PC） | 非破坏性编辑思路、效果器参数体系 | 参数预设化，手机上不暴露专业术语 |
| 各类"音频剪辑"小程序 | 即用即走、微信内分享 | 它们多为"截取+转格式"，我们提供真正的波形级编辑与多轨混音 |

**核心差异化：不依赖后端、完整的波形级非破坏性编辑、微信内闭环分享。**

## 8. 开放的产品问题

1. 小程序名称与品牌：候选「音频工坊」「声剪」「音频剪辑盒」——提审前需查重名与小程序的命名规范。
2. 是否需要"模板"（如播客片头模板、有声书模板）来降低门槛？倾向 P2。
3. 导出 MP3 的授权风险：`lamejs` 为 LGPL，小程序内以 npm 方式静态引入需评估（见 06 文档合规章节）。
4. 导入微信聊天音频的格式分布未知（m4a/silk/amr 混杂），其中 **silk（微信语音）不出现在普通文件选择里**，需要明确不做支持。
