## 登记规则

1. 任何文档改动（新增/修改/状态变更）都必须在下方表格登记一行。
2. 一行对应一次改动，字段齐全：日期 / 文档 / 类型 / 摘要 / 关联代码。
3. `关联代码` 填写该文档对应的代码路径或提交标识；设计阶段写 `未实现`。
4. 走了"紧急修复先改代码"例外路径的，类型标 `[补记]` 并说明原因。
5. 只增不改：历史行不删除、不修改（写错了就再加一行修正）。

**类型取值**：`新增` / `修改` / `状态变更` / `结论回填` / `[补记]`
