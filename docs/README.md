### 平台硬约束

三条决定整体架构的平台限制：**无 `OfflineAudioContext`**、**无音频编码 API**、**Worker 跨线程数据为复制**。

它们的事实、影响与应对方案统一在 [02 §1.1](./02-platform-capability.md#11-音频解码与处理) 与 [02 §2.2](./02-platform-capability.md#22-被否方案与理由)。**动架构前先读 02** —— 本文不重复其论证。

## 术语表

> 术语的一行释义（**完整字段定义见 [05 §2](./05-data-model.md#2-typescript-类型定义)**，算法相关见 [03](./03-audio-engine.md)）：

| 术语 | 含义 | 权威定义 |
| --- | --- | --- |
| **素材（Asset）** | 一次录音或一次导入产生的原始音频，已转成标准中间格式落盘，**永不被修改** | [05 §2](./05-data-model.md#2-typescript-类型定义) |
| **片段（Clip）** | 对某个素材的时间区间的一次引用 | [05 §2](./05-data-model.md#2-typescript-类型定义) |
| **轨道（Track）** | 片段的容器，带增益/声像/静音/独奏/轨道级效果 | [05 §2](./05-data-model.md#2-typescript-类型定义) |
| **EDL** | 描述如何从素材合成出成品的可序列化编辑清单 | [03 §1.1](./03-audio-engine.md#11-三条不变量) |
| **峰值金字塔** | 多级 min/max 降采样数据，用于任意缩放级别高效绘制波形 | [03 §4](./03-audio-engine.md#4-峰值金字塔波形数据) |
| **预览渲染 / 最终渲染** | 为试听渲染短区间 / 导出前全量合成 | [03 §5](./03-audio-engine.md#5-分块渲染管线导出与预览的核心) · [03 §7](./03-audio-engine.md#7-播放与试听策略) |
